Building Tiffin ​

Tiffin is written in Go: tiffind, the tiffin command, the helper and the shims are pure Go, and the app is Go with a Vue frontend (Wails).

bash
make build        # the four programs in ./bin
make check        # gofmt, vet, lint and the tests
make gui-dev      # the app, with live reload, against ./bin/tiffind
make site-dev     # this site
make site-screenshots  # its pictures of the app: a demo tiffind and headless Chrome

The app needs Node 24 with pnpm and the Wails command line; on Linux, GTK 4 and WebKitGTK 6.0 development packages.

How it fits together ​

  • tiffind owns all state. The command line and the app are thin clients over its API (ConnectRPC); neither decides anything itself.
  • tiffin-helper is the only code that runs as root or administrator.
  • New runtimes and services are data: a manifest in the registry, not new code. See Package manifests.

Each design decision is written up as an ADR in the repository's docs/adr folder.
