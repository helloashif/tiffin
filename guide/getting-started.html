Getting started ​

Tiffin is two programs that work together:

  • tiffind, a small background service on your account. It installs runtimes, runs databases, answers .test names and serves your sites. It starts by itself when you first use Tiffin.
  • tiffin (the command) and Tiffin (the app) talk to it. Anything one does, the other can do too.

1. Install ​

bash
curl -fsSL https://helloashif.github.io/tiffin/install.sh | sh
powershell
irm https://helloashif.github.io/tiffin/install.ps1 | iex

The installer downloads the latest release for your OS and architecture, verifies its SHA-256 checksum against checksums.txt, and installs the app and the tiffin CLI.

2. Set the system up, once ​

bash
tiffin elevate

It shows what it will change, asks for your password once, and then:

  • trusts Tiffin's own certificate authority, so https://*.test opens without warnings;
  • sends .test names to tiffind;
  • on Linux, lets tiffind use ports 53, 80 and 443.

The app's Set up button does the same. Everything it changes is listed in What tiffin elevate changes, and tiffin unelevate undoes it.

3. Your first site ​

bash
cd ~/Sites/shop
tiffin link

shop.test now serves the folder (its public/ if it has one, as Laravel does). Open https://shop.test. Or serve every project in a folder at once:

bash
tiffin park ~/Sites      # ~/Sites/blog is blog.test, ~/Sites/shop is shop.test

4. A runtime ​

bash
tiffin add php 8.4
tiffin add node 22
php -v                  # the PHP Tiffin installed

Runtimes and tools explains versions per project.

5. Check everything ​

bash
tiffin doctor

Doctor checks DNS, certificates, ports, PHP and more, and says how to fix what isn't right. See Troubleshooting.

Updating Tiffin ​

tiffind looks for a new release once a day. tiffin self-update installs it:

  • Windows' installer: the new installer runs by itself, then opens Tiffin again.
  • The macOS app: Tiffin.app is replaced as a whole.
  • An archive you unpacked: its programs are replaced where they are.

Then tiffind restarts; quit and reopen the app if it is open. In the app, a note at the bottom of the sidebar says when a release is out, and Settings > Updates installs it and restarts Tiffin by itself. A release counts only when its checksums carry a signature by Tiffin's key for that very version, and each download is checked against them.

bash
tiffin self-update            # install the newest Tiffin
tiffin self-update --check    # only look
tiffin self-update --auto off # stop the daily check (on: turn it back on)

A Linux .deb or .rpm updates the same way: Tiffin downloads the new package, checks its signature, asks for your password once, installs it and restarts. Installed with Homebrew or Scoop? It tells you the package manager's command, which is what updates those.
