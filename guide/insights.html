On this page

Insights ​

Insights reads what Tiffin caught from your running apps and lists what is worth fixing, most severe first. Each finding has a one-line title, a detail, the file and line in your code, a suggested fix and a ref that opens the request it came from.

FindingWhen
n+1one query runs 5 or more times from one line in a request
duplicatethe same query with the same bindings runs twice or more in a request
slow-querya query takes 100 ms or more
slow-requesta request takes 1 s or more, or a route's p95 over the last day is 800 ms or more
repeated-exceptionthe same exception, at the same place, is reported 3 or more times

Queries, request times and exceptions come from the Laravel package (composer require --dev tiffin/laravel, see Dumps and queries); route timings come from every site's requests, and repeated errors are also read from Laravel's log. Only what Tiffin still holds in memory (the newest 500 requests) is analyzed.

bash
tiffin insights                       # every project, the last hour
tiffin insights shop --window 24h     # one project, a longer window
tiffin insights --kind n+1,slow-query # only these kinds
tiffin insights --min-severity error  # only the worst
tiffin insights --slow-query-ms 30    # change a threshold for this run
tiffin insights --json                # for scripts

Each finding ends with how to open it, such as tiffin dumps show a1b2c3d4 for a request or tiffin logs laravel:shop for a log. Severity is error, warning or info; the thresholds are --nplus1-min, --duplicate-min, --slow-query-ms, --slow-request-ms, --route-p95-ms and --exception-min.

In the app ​

Open a project and choose its Insights tab. It lists the findings for that project, errors first, for the last 15 minutes, hour or day. Each one shows its title, where in your code it happens and a suggested fix. Inspector opens the request (or the log) it came from, and the copy button puts the finding on your clipboard for your coding agent. The tab's badge counts the errors and warnings. Home's Needs you list shows the worst findings of every project after any layer that is down; click one to open that project's Insights tab.

For AI agents ​

The MCP server has the same analysis as the read-only insights tool, with the same options (site, window, kind, min_severity, limit and thresholds). Its result quotes your app's SQL and error text, so it is marked as data for the agent, never as instructions.
