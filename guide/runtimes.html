Runtimes and tools ​

Tiffin installs PHP, Node.js, Bun, Deno, Python, Go, Java, .NET, Zig, Erlang, Gleam, everyday developer tools (Composer, WP-CLI, GitHub CLI, pnpm, uv, jq, yq, ripgrep, fzf, and more) from its own signed package registry, several versions side by side, and puts the right one on your PATH in each folder.

Install, list, remove ​

bash
tiffin search                # what the registry offers
tiffin versions php          # the versions with a build for this computer
tiffin add php 8.4           # the newest 8.4.x; or an exact version, or latest
tiffin list                  # what's installed (the default is marked)
tiffin outdated              # what has a newer stable version
tiffin remove node 20.11.1

Downloads are checked against the registry's signed checksums before anything is unpacked.

Erlang & Gleam

  • tiffin add erlang gives you erl, erlc and escript (OTP 27 and newer). On Linux it's hex.pm's build for Ubuntu 22.04, which needs glibc 2.35 or newer and the system's OpenSSL 3; Tiffin runs Erlang's Install step once after unpacking. On Windows it uses the official Erlang/OTP build.
  • tiffin add gleam installs the official Gleam compiler and project toolchain.

.NET, Zig and Git

  • tiffin add dotnet gives you the .NET SDK (dotnet): the newest SDK of each version Microsoft still supports.
  • tiffin add zig gives you Zig (zig), which also serves as a drop-in C and C++ compiler (zig cc).
  • tiffin add git is for Windows: MinGit, the lightweight Git for Windows build made for tools that invoke git, such as Composer and npm. On macOS and Linux, git comes with the system or package manager.

Which version runs ​

Tiffin puts one folder of small programs, its shims, on your PATH. Run php, node or composer and the shim picks the version:

  1. the [runtimes] of the nearest tiffin.toml, in this folder or above;
  2. for PHP in a site's folder, the version chosen with tiffin use <site> <version>;
  3. the global default, set with tiffin use:
bash
tiffin use node 22           # node 22 everywhere nothing else is chosen

So a project's tiffin.toml pins its versions for everyone who works on it:

toml
[runtimes]
php = "8.3"
node = "20"

Putting the shims on your PATH ​

The installers do this for you. Otherwise, once:

bash
tiffin path install          # your shell's startup file, or the user PATH on Windows
tiffin path status

New terminals then find Tiffin's tools; tiffin path uninstall takes them out again.

Disk space ​

Installs keep their downloaded archives; tiffin cache clean deletes them (installed versions don't need them).
