TiffinYour whole dev stack, one tidy box

Runtimes, databases and HTTPS .test sites for every project, on macOS, Windows and Linux. Free, for everyone.

Get started
Command line

Any runtime, per project

PHP, Node, Python, Go, Java, Bun, Deno, .NET, Zig, Gleam, Erlang and everyday developer tools (pnpm, uv, jq, ripgrep, Composer...), installed in seconds and switched per folder. A project's tiffin.toml pins its versions; your terminal just follows.

Sites at https://name.test

Park a folder and every project in it is a site. Trusted local certificates, no hosts file to edit by hand, Laravel's public/ found for you.

Databases and services

PostgreSQL, MySQL, MariaDB, Valkey (Redis), MongoDB, NATS, Qdrant, RabbitMQ, Mailpit and more, each on its own port, started when you need them. Create, back up and restore databases in one command.

One command per project

tiffin up installs what the project's tiffin.toml asks for, starts its services, creates its databases and serves the site. Run it again and nothing changes.

Mail, dumps and logs

Every email your app sends is caught, never delivered. dump() output, queries and N+1 warnings from Laravel, and your logs, readable at last.

Share with anyone

tiffin share gives a site a public https address through a Cloudflare tunnel, no account needed, until you stop it.

An app, and a command line

Everything the app does, tiffin does in a terminal, with --json for scripts. The app adds a tray menu, an inbox and a log viewer.

Fixes itself

tiffin doctor checks DNS, certificates, ports and PHP, says what is wrong and fixes what it can.

Install ​

bash
curl -fsSL https://helloashif.github.io/tiffin/install.sh | sh
powershell
irm https://helloashif.github.io/tiffin/install.ps1 | iex

Then, once, so .test names and HTTPS work (it asks for your password):

bash
tiffin elevate

A project in three commands ​

bash
cd ~/Sites/shop
tiffin add php 8.4      # or let tiffin up read it from tiffin.toml
tiffin link             # serves http://shop.test and https://shop.test

Or describe the project once in tiffin.toml and let tiffin up do the rest:

toml
[runtimes]
php = "8.4"
node = "22"

[services]
postgres = { version = "18", databases = ["shop"] }

[site]
https = true
