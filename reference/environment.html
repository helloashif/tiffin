Environment variables ​

Tiffin needs none of these. They're for moving a port another program holds, a second, separate Tiffin (tests, a portable install) or a registry of your own. Set them where tiffind starts (your shell, or the login item), then tiffin stop: it starts again with them on the next command.

VariableDefaultWhat
TIFFIN_HOMEyour system's folders (Files and ports)One folder for all of Tiffin's data, settings and logs: a separate Tiffin.
TIFFIN_DNS_ADDR127.0.53.1:53 (Windows, Linux), 127.0.0.1:1053 (macOS)Where tiffind answers .test names: a loopback ip:port. On Linux, before tiffin elevate, it falls back to 127.0.0.1:1053.
TIFFIN_HTTP_ADDRport 80, else 8080, on 127.0.0.1 and ::1Where sites are served over HTTP: one loopback ip:port.
TIFFIN_HTTPS_ADDRport 443, else 8443The same for HTTPS.
TIFFIN_SMTP_ADDR127.0.0.1:2525Where mail is caught. PHP is pointed at it by itself.
TIFFIN_DUMPS_ADDR127.0.0.1:9913Where the Laravel package sends dumps and queries. Sites Tiffin serves get it through their environment.
TIFFIN_REGISTRY_URLTiffin's registryWhere packages come from. Only registries signed with a key built into Tiffin are accepted; there is no way to add a key at run time.
TIFFIN_OFFLINEunset1: never fetch the package list; use the copy Tiffin has.
TIFFIN_NO_UPDATE_CHECKunset1: tiffind doesn't look for a new Tiffin once a day. tiffin self-update still checks when asked.
TIFFIN_NO_AUTOSTARTunset1: tiffin commands don't start tiffind when it isn't running.
TIFFIN_DAEMONthe tiffind beside tiffinThe tiffind to start: an absolute path.
TIFFIN_TRANSPORTpipe (Windows), unix (others)How tiffin and the app reach tiffind: a named pipe or a Unix socket.
TIFFIN_ALLOW_ELEVATEDunset1: let tiffind run as root or administrator. Only for CI machines that run everything that way; never on your own computer.

The DNS, SMTP and dumps addresses can also be saved with tiffin config set; a variable that is set wins over the saved address.

Ports must be on a loopback address (127.x.x.x or ::1): Tiffin never listens on your network.

Set by Tiffin, for your app ​

Not for you to set: Tiffin gives these to PHP for each request.

VariableWhat
TIFFIN_REQUEST_IDThe proxy's id for this request (16 hex digits). The Laravel package files the request's dumps under it, which links them to the request the proxy kept, for sending it again. A server variable: a request header can't set it.

For the Laravel package, TIFFIN_ENABLED=false in an app's .env turns it off (see Dumps and queries).
